# moodtracker

just a my mood in the website https://oxidemood.onrender.com/ and i control it with telegram bot

## Bot commands

Mood message:

- `спокій`
- `радість | після кави`
- `🌧️ сумно | дощ | 3`

Live controls:

- `/doing коджу`
- `/listen Radiohead — Weird Fishes`
- `/status free|focus|away|sleep`
- `/signal назад через годину`
- `/theme lagoon|ember|moss|ink|bloom`
- `/clear doing|listening|signal|all`
- `/now`
- `/help`
